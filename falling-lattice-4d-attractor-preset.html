Construction

For p=(i,j,k) ∈ ℤ³, let r=‖p‖₂ and R=√3 N. The deformed tether length is Lκ(r)=r exp(κr/R). In the directional model, the current implementation matches the earlier version: the taut trajectory rotates the deformed node toward −w while preserving the tether length. In the point-attractor model, each node is steered toward a user-chosen point A=(ax,ay,az,aw) in ℝ⁴.

Interpretation

The slider labeled “final radial fraction / attractor blend” keeps its old meaning in the directional model and becomes an attractor-blend parameter in the point-attractor model: values near 1 preserve the original direction, values near 0 align more strongly toward the attractor. Dense mode renders all selected points but disables paths, tethers, original nodes, and hover inspection for speed. The lattice is truncated to a finite cube.
