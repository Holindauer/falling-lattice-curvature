Model notes

From the upper grid to landing rings

Each integer site (i, j) in the release disk starts at z = 0. The origin O stays pinned there. Sort the distinct positive values of r = √(i² + j²) into shells r₁ < r₂ < … < rₘ. Every site in shell j lands on the circle of horizontal radius jΔ. The innermost ring is Δ from the axis, and each successive ring is another Δ out.

Shells include noninteger radii such as √2 and √5. On each landing circle the sites take equal angular steps of 2π divided by the shell’s population. Their cyclic order is preserved. The guide rotates each regular polygon to minimize the sum of squared angular shifts from the release sites.

The vector that catches the site

Each edge O → P has a release weight ℓ. The straight arrow from O to the current P has norm d = √(ρ² + z²), where ρ = √(x² + y²). The ring catches the site when its horizontal radius is jΔ and d reaches the ring’s assigned vector length Dⱼ.

Equal steps sets Dⱼ = jℓₘ/m for m shells. Consecutive landing rings are equally spaced both in the xy plane and in distance from O. Release weights sets Dⱼ = ℓⱼ, preserving each edge’s original weight as its landing norm. The xy gaps stay uniform in both settings.

ρⱼ = jΔ   zⱼ = −√(Dⱼ² − ρⱼ²)

The negative root places every ring below the upper lattice. The ring spacing keeps the smaller rings higher and the larger rings lower. During flight d can vary. The inspector also integrates distance along the curved trajectory from release to the current point.

Watching the fall

All sites are released together from rest. Their vertical position follows z = −gt²/2 until each ring catches its sites. The inner rings land first. The progress slider runs from release to the instant the outermost ring lands.

The model specifies lateral guides because the landing circles alone allow many flight paths. For a site’s fraction q of its own fall time, the guide uses b = 3q² − 2q³ to interpolate both its grid radius and its unwrapped azimuth. This starts the horizontal motion from rest and ends it smoothly at the ring. Playback holds each site in place after landing.

What curvature changes

κ gives the horizontal release sheet a constant-curvature metric. A unit at the origin agrees with a grid unit. The release weight of a site at grid radius r is its intrinsic distance from O along that sheet.

ℓκ(r) = ∫₀ʳ ds / (1 + κs²/4)

At κ = 0 the release weight equals r. Negative κ lengthens it and positive κ shortens it. The landing rule uses these weights to set the target norms. Turn on Unit contours to see one-unit intervals of this intrinsic distance on the original grid. Landing gaps, position vectors and traveled paths are measured in the displayed Euclidean space.

How the uniform gap is chosen

The gap slider chooses a fraction of the widest spacing that keeps this finite set of rings in order. Its readout gives the actual Δ in grid units. Changing the lattice radius or curvature recomputes this spacing. With D₀ = 0 the bound is

Δmax = minⱼ { rⱼ / j, √[(Dⱼ² − Dⱼ₋₁²) / (2j − 1)] }.

Using 0 < Δ < Δmax places every target ring inside its release radius. It also makes Dⱼ² − (jΔ)² strictly increase with j, so each outer ring lands lower than the preceding one. The radial gap is common across shells. The distance between adjacent sites around one ring depends on how many sites that shell contains.

Reading and operating the views

Hollow marks denote release sites. Filled marks show the current positions. The cross at O is the fixed origin. Both views highlight the same selected trajectory and landing ring in amber. One shell isolates all the sites with that release radius. Vectors draws the directed edges.

Click a site in either view or choose its integer coordinates below the plots. The camera keeps O fixed while fitting the complete descent. Drag the spatial view or use its arrow keys to orbit. Scroll, pinch or press + / − to zoom. Side shows ring heights in profile. Home restores the opening view.
